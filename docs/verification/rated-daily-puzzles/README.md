# Rated and daily puzzle evidence

Puzzles now offers Rated, Daily and Custom practice. Rated chooses unseen local puzzles using Standard, Hard and Extra Hard difficulty bands. A clean full solution wins; the first legal mistake, hint, reveal or skip scores one loss. Continuing practice does not rescore the attempt. Each receipt records before, after, delta and result; the receipt and profile update commit atomically. Try again always creates custom practice.

The local rating starts at 1500 and uses fixed-source Elo with K=32. Relative source-rating selection bands are Standard -450 to -150, Hard -250 to +50 and Extra Hard -150 to +150. Empty bands fall back to the nearest installed difficulty. Seen puzzles are excluded; after bounded random draws an indexed source query finds any remaining unseen entry. Local ratings are not proprietary Chess.com ratings or calibrated chess playing strength.

Daily pins a legal source snapshot for the server-local date, shared by all accounts. An account/date has one daily attempt. Repeated starts return it; attempts spanning midnight retain their source date. Solving credits that date once. The consecutive streak includes today, or ends yesterday while today is pending. Daily replay is custom practice and cannot duplicate daily credit or change rated scores. Account isolation, hidden solutions, original FEN/history and separate native analysis remain protected.
