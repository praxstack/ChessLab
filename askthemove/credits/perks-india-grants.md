# Startup perks, India schemes and grants for AskTheMove (as of 2026-10-09)

Founder profile: solo, India, bootstrapped, **no registered company**, no investors. Has a company-domain email (prax@askthemove.online), a live website/waitlist (askthemove.online), and GitHub. App not hosted yet.

Verification legend: **[OFF]** = read on the official page this session. **[OFF-partial]** = official page fetched but some fields missing or JS-rendered. **[SEC]** = only secondary/aggregator sources reachable. **[UNV]** = could not verify; treat as a lead.

## Key finding: what actually gates you

1. **Company-domain email + website.** Many programs need these (PostHog, Notion, Kiro, Google Cloud, Anthropic). **You already have both.** Zoho Mail on your own domain counts as a company email.
2. **Outside funding or partner/VC referral.** This rules out GitHub for Startups, Linear, Framer, Atlassian, HubSpot 90%, Replit credits, Lovable, AWS Portfolio and Google Cloud $200K. **Incorporating does not fix this one.**
3. **Indian incorporation (Pvt Ltd/LLP) + DPIIT.** Needed for every government scheme (Startup India, SISFS, MeitY GENESIS, state grants, IndiaAI compute, Zoho for Startups).
4. **US entity.** Needed for Mercury and in practice Brex/Ramp, and on acceptance for AI Grant. Stripe Atlas creates one.

Many SaaS perks **never ask about incorporation.** They check stage, funding raised (under $5–10M) and email domain. You can claim these now.
