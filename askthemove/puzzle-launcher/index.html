    First time on this device? Open a blank Chess.com board and flip its Analysis switch off before your first puzzle, so the engine can’t show you the answer. Chess.com remembers it on this device. Switch it back on when you want to check.

    Black to move? Use Chess.com’s flip button so Black sits at the bottom.

    What can I paste?
    • FEN: one position, like 8/8/8/4k3/8/8/4P3/4K3 w - - 0 1.
    • PGN: a whole game or just its moves, like 1. e4 e5 2. Nf3.
    • Chess.com game link: opens that game in Chess.com’s analysis.
    • Chess.com daily puzzle link: works like picking that date.
    • Lichess game, puzzle or study link: this page fetches its moves and opens them on Chess.com.
    • Any link with fen= in it.

    Chess.com’s puzzle links (Puzzles, Puzzle Rush) can’t be read from outside, so they open as they are.

      Add this page to your home screen

      iPad (Safari)

      1. Tap the Share button (square with an arrow).
      2. Tap Add to Home Screen, then Add.

      Android (Chrome)

      1. Tap the ⋮ menu at the top right.
      2. Tap Add to Home screen, then Add.
      Bookmarklet (backup)

      A bookmark that opens today’s puzzle on Chess.com’s analysis board. Run it while you’re on a Chess.com page. Some other sites block it, and then it says it couldn’t load the puzzle.

      iPad (Safari)

      1. Bookmark any page: Share, then Add Bookmark. Name it Puzzle.
      2. Open Bookmarks, tap Edit, tap the Puzzle bookmark.
      3. Delete its address and paste the code. Tap Done.
      4. To use it, open any Chess.com page, then tap Puzzle in your bookmarks.

      Android (Chrome)

      1. Bookmark any page with the ☆ in the ⋮ menu, then tap Edit.
      2. Name it Puzzle, delete its URL and paste the code.
      3. To use it, open any Chess.com page, type Puzzle in the address bar and tap the bookmark that shows up. (Picking it from the bookmarks list doesn’t run it on Android.)

      Puzzle positions and games come from the Chess.com public API and the Lichess API. This page never shows a puzzle’s answer or name. Not made by Chess.com or Lichess.
