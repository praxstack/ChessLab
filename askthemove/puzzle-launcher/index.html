Add this page to your home screen

  1. Tap the Share button (square with an arrow).

  1. Tap the ⋮ menu at the top right.

Bookmarklet (backup)

A bookmark that opens today’s puzzle on Chess.com’s analysis board. It works from any normal web page, Chess.com included.

iPad (Safari)

  1. Bookmark any page: Share, then Add Bookmark. Name it Puzzle.
  2. Open Bookmarks, tap Edit, tap the Puzzle bookmark.
  3. Delete its address and paste the code. Tap Done.
  4. To use it, open any page, then tap Puzzle in your bookmarks.

Android (Chrome)

  1. Bookmark any page with the ☆ in the ⋮ menu, then tap Edit.
  2. Name it Puzzle, delete its URL and paste the code.
  3. To use it, open any page, type Puzzle in the address bar and tap the bookmark that shows up. (Picking it from the bookmarks list doesn’t run it on Android.)

This page only reads the puzzle’s position from the Chess.com public API. It never shows the answer or the puzzle’s name. Not made by Chess.com.
