Coverage and provenance

The library covers the supplied startup research, learning-product comparison, PDF, recovered conversation, lesson images, previous assessment, project context, instructions, setup guide, OpenSpec configuration and all four draft artifacts, skill manifest, setup helper and this dossier's chapters and build assets.

Linked global skill packs are external dependencies. This dossier records their identities, paths and entrypoint hashes; it does not bundle their runtime trees or imply they will install on another machine simply by opening the HTML.

New sources captured for the dossier have their own hashes in the generated manifest. The three originally supplied files retain their existing provenance record. HTML pages are generated views; edit the source Markdown or presentation assets and rebuild instead of editing generated pages.

Use the printable version of each reading page through your browser's Print command. The portable archive contains the site and original downloads, not an application release or an installation package for the skill packs.
