Git and release truth

At the start of this run, the 26 earlier setup files were still staged and the repository had no commits. The earlier commit command failed because the configured SSH signing key could not be unlocked. An SSH agent connection was unavailable. Signing was not disabled and no credential files were changed.

This run preserves that staged work and adds the dossier in the working tree. It does not claim a commit, push, public website or released chess app. An authorized user can unlock the signing key and complete the baseline later. The report is usable locally without that commit.
