# Local Vision training

Add mapped board-vision gap CAP-097. Reference inspected 13 September 2026: https://support.chess.com/en/articles/8615408-what-is-vision and rendered https://www.chess.com/vision. Setup exposes Coordinates, Moves, Coordinates & Moves; White, Black, White or Black; coordinate labels. A live Moves round showed a three-second countdown, 30-second clock, lone queen and notation prompt. Destination-only clicking did not score; dragging the queen to the named square scored and advanced. Completion displayed score and restart setup. Help text alone does not describe the gesture accurately.

Implement this locally with protected clocks and private history. Added scope: explicit quit, keyboard input, restart/reload recovery, and varied non-pawn pieces. These additions are not observations of vendor behavior. No complete vendor distribution, statistics, accessibility or learning-efficacy claim. Preserve existing games, studies, engines and scores.
