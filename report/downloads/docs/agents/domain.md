# Domain documentation

Use a single context. Read root `CONTEXT.md` before exploration and relevant files in `docs/adr/` when present. Use the glossary's names for game, snapshot, branch, anchor, evidence and explanation.

Missing ADRs are not an error. Create them when a real architecture decision is made. Surface conflicts with accepted decisions; do not silently rewrite them. No monorepo or multiple-context layout is needed at this stage.
