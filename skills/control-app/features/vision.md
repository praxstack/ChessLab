# Vision training

Enter Vision from the main navigation. Configure Coordinates, Moves or Coordinates & Moves, White/Black/random perspective, and coordinate labels. A local account owns every round.

Start waits through a three-second countdown. Coordinates accept a square click, tap or typed square. Moves accept origin/destination clicks, dragging, touch, SAN for the displayed piece or origin/destination notation. Wrong answers retain the prompt and piece; correct answers advance once. The server's 30-second deadline continues through navigation/reload. Mobile displays a compact prompt next to the board. End round early is excluded from bests; completed rounds and matching-setting bests remain local.

The full browser harness exercises countdown, wrong/right coordinates, keyboard board input, timed completion, reload, flipped move dragging, actual mobile touch, mixed mode, early ending and persisted history. The API suite covers concurrent revisions, foreign/guest denial, early/late/malformed answers, restart, all 18 setting combinations and unchanged game/puzzle/lesson tables. A second rules library checks movement for all five non-pawn pieces on all 64 squares in both orientations.

No claim of vendor exercise-distribution equivalence, pawn/promotion curriculum, guest scoring, public rankings or measured learning outcomes.
