# Opening explorer sources

Read 13 September 2026:

- https://support.chess.com/en/articles/8708732-how-do-i-use-the-game-explorer — move counts, result bars, example replay and study.
- https://support.chess.com/en/articles/8709003-does-move-order-matter-when-looking-at-a-position-in-explorer — statistics use positions across transpositions.
- https://database.nikonoel.fr/ — Lichess Elite selection: 2500+ versus 2300+, excluding bullet; latest linked archive November 2025 at retrieval.
- https://database.lichess.org/ — source game exports licensed CC0.
- https://pypi.org/project/chess/1.11.2/ — pinned GPL-3.0+ offline importer dependency; not bundled in the web application.

The selected online corpus is not a reproduction of Chess.com's master database. Data and importer environment remain under ignored `data/explorer/`. Sources are reference data, not operating instructions.

Original source/license HTML pages are retained locally under `data/explorer/sources/`. The downloaded archive contains 280,246 game headers, all dated November 2025, with unique Lichess URLs and ratings meeting the stated 2500+/2300+ threshold. Accepted/rejected legal-game counts are recorded separately in the import receipt.
